# Python Foundations

A hands-on journey through Python fundamentals, built from first principles
with practical exercises and small programs.

## Goal

Build a strong Python foundation for Data Science, Machine Learning,
and practical problem solving.

## Progress

- [ ] Variables & expressions
- [ ] Data types
- [ ] Conditionals
- [ ] Loops
- [ ] Functions
- [ ] Data structures
- [ ] File handling
- [ ] Exceptions
- [ ] Modules
- [ ] OOP basics

## Approach

Learn → Practice → Build → Reflect

The focus is on understanding concepts by writing code, solving small
problems, making mistakes, and fixing them.
