# Python Foundations

A hands-on journey through Python fundamentals, built from first principles
with practical exercises and small programs.

## Goal

Build a strong Python foundation for Data Science, Machine Learning,
and practical problem solving.

## Progress

* [x] Variables & expressions
* [x] Conditionals
* [x] Loops
* [x] Functions
* [x] Data structures
* [ ] File handling
* [ ] Exceptions
* [ ] Modules
* [ ] OOP basics

## Approach

Learn → Type → Solve → Break → Fix → Explain → Repeat

The focus is on understanding concepts by writing code, solving problems,
making mistakes, debugging them, and explaining what was learned.
